## 1. 概述

Dify Web 项目采用多层次的认证架构，支持多种登录方式：

- **邮箱密码登录**：传统的用户名密码认证
- **邮箱验证码登录**：无密码登录方式
- **社交登录**：GitHub、Google OAuth
- **企业 SSO**：SAML、OIDC、OAuth2 协议

系统使用 JWT Token 进行身份验证，支持 Token 自动刷新和跨标签页同步。

### 4.2 Token 刷新机制

**文件路径**: `service/refresh-token.ts`

**关键特性**:
- **跨标签页同步**: 使用 localStorage 标志 `is_other_tab_refreshing` 防止多标签页同时刷新
- **超时控制**: 使用 `Promise.race()` 实现 100 秒超时
- **单一请求**: 确保只有一个刷新请求在进行中

**刷新流程**:

```typescript
async function getNewAccessToken(timeout: number): Promise<void> {
  // 1. 检查其他标签页是否正在刷新
  if ((isRefreshingSign && isRefreshingSign === '1' && isRefreshingSignAvailable(timeout)) || isRefreshing) {
    await waitUntilTokenRefreshed()
  }
  else {
    // 2. 设置刷新标志
    isRefreshing = true
    globalThis.localStorage.setItem(LOCAL_STORAGE_KEY, '1')
    globalThis.localStorage.setItem('last_refresh_time', new Date().getTime().toString())

    // 3. 调用刷新 API
    const [error, ret] = await fetchWithRetry(globalThis.fetch(`${API_PREFIX}/refresh-token`, {
      method: 'POST',
      credentials: 'include',
      headers: { 'Content-Type': 'application/json;utf-8' },
    }))

    // 4. 处理响应
    if (error)
      return Promise.reject(error)
    if (ret.status === 401)
      return Promise.reject(ret)
  }
}

export async function refreshAccessTokenOrRelogin(timeout: number) {
  return Promise.race([
    new Promise<void>((resolve, reject) => setTimeout(() => {
      releaseRefreshLock()
      reject(new Error('request timeout'))
    }, timeout)),
    getNewAccessToken(timeout)
  ])
}
```

## 6. OAuth/SSO 第三方登录

### 6.1 OAuth 授权流程

**文件路径**: `app/account/oauth/authorize/page.tsx`

**流程**:
1. 用户访问 `/account/oauth/authorize?client_id=xxx&redirect_uri=xxx`
2. 检查用户是否已登录
3. 如果未登录，显示登录按钮
4. 如果已登录，显示授权范围和用户信息
5. 用户点击"继续"后，调用 `/oauth/provider/authorize` API
6. 获取授权码，重定向到 `redirect_uri?code=xxx`

**授权范围 (Scopes)**:

| Scope | 描述 |
|-------|------|
| `read:name` | 读取用户名 |
| `read:email` | 读取邮箱 |
| `read:avatar` | 读取头像 |
| `read:interface_language` | 读取界面语言偏好 |
| `read:timezone` | 读取时区 |

**关键代码**:

```typescript
const onAuthorize = async () => {
  if (!client_id || !redirect_uri)
    return
  try {
    const { code } = await authorize({ client_id })
    const url = new URL(redirect_uri)
    url.searchParams.set('code', code)
    globalThis.location.href = url.toString() // 重定向到应用
  }
  catch (err: any) {
    Toast.notify({
      type: 'error',
      message: `${t('error.authorizeFailed', { ns: 'oauth' })}: ${err.message}`,
    })
  }
}
```

```typescript
export const resolvePostLoginRedirect = (searchParams: ReadonlyURLSearchParams) => {
  // 1. 检查 URL 参数中的重定向 URL
  const redirectUrl = searchParams.get(REDIRECT_URL_KEY)
  if (redirectUrl) {
    try {
      localStorage.removeItem(OAUTH_AUTHORIZE_PENDING_KEY)
      return decodeURIComponent(redirectUrl)
    }
    catch (e) {
      console.error('Failed to decode redirect URL:', e)
      return redirectUrl
    }
  }

  // 2. 检查 localStorage 中的待处理授权
  return getItemWithExpiry(OAUTH_AUTHORIZE_PENDING_KEY)
}
```

## 9. 认证流程图

### 9.1 主登录流程

```
用户访问 /signin
       │
       ▼
检查登录状态 (useIsLogin)
       │
       ├─── 已登录 ──→ 重定向到 /apps 或指定 URL
       │
       ▼
     未登录
       │
       ▼
显示登录选项
       │

       │
       ├─── 邮箱验证码 ──→ /email-code-login ──→ /signin/check-code ──→ /email-code-login/validity
       │
       ├─── 社交登录 ──→ /oauth/login/{github|google} ──→ 后端处理
       │
       └─── SSO ──→ /enterprise/sso/{saml|oidc|oauth2}/login ──→ 后端处理
       │
       ▼

       │
       ├─── 检查邀请链接 ──→ /signin/invite-settings

       ├─── 检查 OAuth 授权待处理 ──→ /account/oauth/authorize
```
