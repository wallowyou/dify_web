# app/layout.tsx 入口文件分析

本文聚焦于 Next.js App Router 的根布局文件 app/layout.tsx，解析其职责、渲染结构、全局 Provider 及配置注入方式。

## 1. 文件定位与运行时属性

- 这是 App Router 的根布局文件，所有页面都会被其包裹
- 该组件为 Server Component（未标注 use client），可以直接读取服务端环境变量
- 提供全局 viewport 配置，控制移动端缩放与视口适配

## 2. 全局样式与字体

- 引入全局样式：app/styles/globals.css、app/styles/markdown.scss
- 使用 next/font/google 注入 Instrument Serif 字体，并通过 CSS 变量应用到 html 上

## 3. 服务器端语言与资源初始化

- 通过 getLocaleOnServer 获取当前语言
- 将 locale 注入 html lang 属性，同时传给 I18nServerProvider 加载对应资源

## 4. 环境配置注入（datasetMap）

- datasetMap 将多个环境变量以 data-* 的形式挂载到 body 上
- DatasetAttr 提供统一的 data-* key，确保配置与前端读取逻辑一致
- 这些 data-* 值被 config 模块用于初始化 API 前缀、Sentry DSN、Cookie 域名、功能开关等

## 5. HTML 结构与 Head 注入

- Head 中包含 PWA 相关 meta、manifest 与 icon
- body 设置 color-scheme 与 select 行为
- Service Worker 地址通过 NEXT_PUBLIC_BASE_PATH 计算

## 6. 全局 Provider 链路

以下为 Provider 栈顺序（由外至内），决定了运行时上下文初始化顺序：

1. SerwistProvider
   - 注册 service worker，并提供 PWA 支持
2. ReactScanLoader
   - 仅开发环境加载性能扫描工具
3. JotaiProvider
   - 提供全局原子状态管理
4. ThemeProvider
   - 主题与系统暗色模式切换
5. NuqsAdapter
   - URL 查询参数状态同步
6. BrowserInitializer
   - 处理 localStorage/sessionStorage 兼容
7. SentryInitializer
   - 在生产环境按 data-public-sentry-dsn 初始化 Sentry
8. TanstackQueryInitializer
   - 初始化 React Query 客户端与 Devtools
9. I18nServerProvider
   - 注入国际化资源与语言
10. ToastProvider
    - 全局通知系统
11. GlobalPublicStoreProvider
    - 拉取 systemFeatures 与 setupStatus 并缓存

## 7. 路由前缀处理

- RoutePrefixHandle 监听 DOM 中 img 的 src，自动补齐 basePath
- 用于部署在子路径时，修正资源访问路径

## 8. 关键文件索引

- app/layout.tsx：入口布局文件
- app/components/browser-initializer.tsx：存储兼容与 polyfill
- app/components/sentry-initializer.tsx：Sentry 初始化
- context/query-client.tsx：React Query 初始化
- context/global-public-context.tsx：系统功能与初始化状态
- app/components/provider/i18n-server.tsx：国际化服务端注入
- app/components/provider/serwist.tsx：Service Worker Provider
- app/components/devtools/react-scan/loader.tsx：性能扫描工具
- app/routePrefixHandle.tsx：basePath 处理
